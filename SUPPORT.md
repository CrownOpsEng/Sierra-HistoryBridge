# Support

Sierra History Bridge is experimental software for Windows and Sierra Chart.
Review the [publishing and installation](docs/PUBLISHING.md),
[usage](docs/USAGE.md), and [troubleshooting](docs/TROUBLESHOOTING.md)
documentation before requesting help.

Use the structured GitHub issue forms for reproducible bugs and focused feature
requests. Support is provided on a best-effort basis; no response time or
service level is promised.

Always reproduce problems with copied SCID or DLY files. Never attach brokerage
credentials, account secrets, unrelated trading records, or an active Sierra
Chart Data folder.

Report vulnerabilities and sensitive integrity problems through [GitHub private
vulnerability reporting][private-report]. Conduct reports and corporate CLA
exchange requests must use a private contact method listed on the
[CrownOpsEng GitHub profile][maintainer].

[maintainer]: https://github.com/CrownOpsEng
[private-report]: https://github.com/CrownOpsEng/Sierra-HistoryBridge/security/advisories/new
